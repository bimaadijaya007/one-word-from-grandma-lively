Entry for the make.fun bounty [One Word from Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16) — the single word grandma would text about AI.

## The word

**doohickey** — the classic grandma name for a gadget she cannot quite name.

## Run

```sh
node main.ts
```

Writes exactly `doohickey` (9 characters, no newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads it back and verifies it byte-for-byte.
